# Workers Screen Developer Guide

This folder contains screens for worker management.

## Files

- **WorkersScreen.kt**: Worker list and entry point to add/edit flows.
- **WorkerDetailScreen.kt**: Worker detail view with shifts, events, payments, and photos. Reference payment cards (`תשלומי הפניה`) display the referred worker's name alongside the project/event name.
- **AddWorkerScreen.kt**: Form to create a new worker.
- **EditWorkerScreen.kt**: Form to update an existing worker.
